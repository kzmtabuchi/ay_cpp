# ソフトウェア仕様書: cpp_util.h

## 1. 概要
本ライブラリは、C++開発における統計計算、文字列操作、パス結合などの汎用的な機能を提供するヘッダーファイルのみのユーティリティ集です。

## 2. 基本情報
- **ファイル名**: cpp_util.h
- **名前空間**: trick
- **作成者**: Akihiko Yamaguchi (info@akihikoy.net)
- **バージョン**: 0.1
- **最終更新日**: 2018年2月28日

## 3. 関数仕様

### 3.1 統計・数値計算
| 関数名 | 説明 | 備考 |
|:---|:---|:---|
| `Sq(val)` | 値の2乗を計算する。 | テンプレート引数 |
| `Mean(vec)` | ベクトル要素の平均値を算出する。 | |
| `Median(vec)` | ベクトルの中央値を算出する。 | **注意: vecをソートするため、元の順序が変更される。** |
| `Percentile(vec, q)` | qパーセンタイル値を算出する。 | **注意: vecをソートするため、元の順序が変更される。** |
| `PercentileByIndex(v, p)` | インデックスベースでpパーセンタイル値を算出する。 | `std::nth_element`を使用する高速版。 |

### 3.2 文字列操作
| 関数名 | 説明 | 備考 |
|:---|:---|:---|
| `ToString(prefix, num, posix)` | プレフィックス、数値、サフィックスを連結する。 | |
| `IsInt(s)` | 文字列が整数として有効か判定する。 | 空白や不適切な文字が含まれる場合はfalse。 |
| `ToInt(s)` | 文字列を整数型に変換する。 | `atol`を使用。 |
| `SplitString(str, delim)` | 文字列を特定の区切り文字で分割し、リスト化する。 | 戻り値版と参照渡し版の2種。 |

### 3.3 データ探索
| 関数名 | 説明 | 備考 |
|:---|:---|:---|
| `FindIndex(vec, val)` | ソート済みベクトルから `vec[idx] <= val < vec[idx+1]` となるインデックスを返す。 | 挿入位置の特定等に利用。 |

### 3.4 ファイルパス操作
| 関数名 | 説明 | 備考 |
|:---|:---|:---|
| `PathJoin(base, file)` | ディレクトリパスとファイル名を結合する。 | `file`が'/'で始まる場合は絶対パスを優先。 |
| `PathJoin(base, files)` | ディレクトリパスと複数のファイル名を一括結合する。 | 文字列のベクトルを返す。 |

## 4. 依存関係
- C++ 標準ライブラリ: `<sstream>`, `<cstdlib>`, `<cctype>`, `<vector>`, `<string>`, `<algorithm>`, `<cmath>`

## 5. 使用上の注意
- `Median` および `Percentile` 関数は非const参照を受け取り、内部で要素をソートします。入力データの順序を維持する必要がある場合は、呼び出し側でデータのコピーを作成してください。
