# ソフトウェア仕様書: sys_util.h

## 1. 概要
`sys_util.h` は、OS（Linux/Windows）間の差異を吸収し、高精度な時刻取得、ループ頻度の調整（レート制御）、ファイル存在確認などのシステムレベルのユーティリティを提供するC++ライブラリです。

## 2. 基本情報
- **名前空間**: `trick`
- **作成者**: Akihiko Yamaguchi (info@akihikoy.net)
- **バージョン**: 0.2 (2018年9月30日 Windows対応改訂版)
- **依存ライブラリ**: 標準C++11 (`chrono`, `thread`, `fstream`), OS固有API (POSIX / Windows API)

## 3. 公開関数リファレンス

#### **GetCurrentTime**
- **引数**: なし
- **戻り値**: `double` (秒単位の現在時刻)
- **内容**: システムから現在時刻を取得し、秒単位の浮動小数点数で返します。
- **OS固有の挙動とリスク**:
  - **Linux**: `gettimeofday` を使用（マイクロ秒精度）。システム時計の変更に影響を受けます。
  - **Windows**: `QueryUnbiasedInterruptTime` を使用（100ナノ秒単位）。システムがスリープや休止状態の間、カウントが停止する「バイアスのない」割り込み時間を参照します。
  - **リスク**: OSによって時刻の起点（エポック）や精度が異なるため、異なるOS間で絶対時刻を比較する用途には適しません。

#### **GetCurrentTimeL**
- **引数**: なし
- **戻り値**: `int64_t` (マイクロ秒単位の現在時刻)
- **内容**: システムから現在時刻を取得し、整数型のマイクロ秒単位で返します。
- **リスク**: Linuxでは1970年からの経過秒に基づく大きな値となります。Windowsでは起動時からの累積時間等に基づくため、値の大きさが環境により極端に異なります。

#### **FileExists**
- **引数**: `const std::string &filename`
- **内容**: 指定されたパスのファイルが存在し、読み取り可能であるかを確認します。
- **内部処理**: `std::ifstream` を開き、オープンに成功するかどうかで判定します。
- **リスク**: ファイルが存在しても、実行ユーザーに読み取り権限がない場合は `false` を返します。また、ディレクトリの存在確認には適さない場合があります。

## 4. 公開クラスリファレンス: TRateAdjuster

一定の周波数（Hz）でループ処理を実行するためのレート調整クラスです。

#### **TRateAdjuster (コンストラクタ)**
- **引数**: `const double &frequency` (目標周波数 [Hz])
- **内容**: インスタンスを初期化し、目標とするサイクル時間（1.0 / frequency）を計算します。

#### **Sleep**
- **引数**: なし
- **内容**: 前回の実行時刻に基づき、目標の周波数を維持するために必要な時間だけ現在のスレッドをスリープさせます。
- **ロジックの詳細**: 
  1. 次回開始予定時刻（expected_next_start_）と現在時刻の差分を計算します。
  2. 処理が目標時間を超過している場合（スリープ時間が0以下）、スリープせずに即座に復帰します。
  3. `std::this_thread::sleep_for` を用いてナノ秒単位で待機します。
- **リスク**: 
  - **OSスケジューラの影響**: スリープの精度はOSのスケジューラに依存します。特に Windows 等では、指定した時間よりも長く待機してしまう可能性があります。
  - **大幅な遅延**: 実際の処理時間が目標サイクルを大幅に超えた場合、内部時刻（expected_next_start_）が現在時刻にリセットされ、過去の遅れを取り戻そうとする挙動を抑制します。

#### **Reset**
- **内容**: レート調整の基準時刻を現在時刻にリセットします。ループの開始直前や、処理を再開する場合に使用します。

#### **ActualCycleTime / ExpectedCycleTime**
- **内容**: 前回のループで実際にかかったサイクル時間、および目標とする設定サイクル時間を取得します。

## 5. 安全管理・使用上の注意
1. **Windows環境の注意**: `Windows.h` のインクルードに伴うマクロの衝突を防ぐため、内部で `NOMINMAX` の定義および `GetCurrentTime` マクロの `undef` を行っています。他のライブラリとの併用時に名前衝突のリスクがあります。
2. **リアルタイム性**: 本ライブラリはハードリアルタイム性を保証するものではありません。特に `TRateAdjuster` は、OSのバックグラウンド処理等によって周波数が不安定になる可能性があります。
3. **時刻の巻き戻し**: システム時刻を手動で変更した場合、`GetCurrentTime` の戻り値が逆転し、`TRateAdjuster` 等の挙動が破綻するリスクがあります。
